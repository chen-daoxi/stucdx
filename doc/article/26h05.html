Stars Basic Script(SBS)开发日志

陈
小陈同学-STUCDX

本文章记录了Stars Basic Script(SBS)的开发日志

Stars Basic Script V0.1[26Y07V2801]

更新日志

  • 1.实现了Lexer类，增加了许多类型如：KEYWORD,NUMBER,STRING...
  • 2.实现了词法分析

附件：Stars Basic Script V0.1[26Y07V2801].exe

;nbsp

Stars Basic Script V0.2[26Y07V2902]

更新日志

  • 1.增加了变量表，用户可以通过set关键字来给变量赋值
  • 2.在KEYWORD类中增加了 set 关键字
  • 3.在KEYWORD类中增加了 output 关键字，用户可以通过此关键字来输出
  • 4.增加了如果输入是空格就contiue的判断
  • 5.增加了如果输入为exit就break的判断
  • 6.增加了如果输入为output [变量]就输出变量的功能
  • 7.增加了如果输入为var就输出所有变量的判断
  • 8.增加了许多报错（不列了自己去试）
  • 9.增加了如果输入为number类就像python一样输出这个数字的功能

附件：Stars Basic Script V0.2[26Y07V2902].exe

Stars Basic Script V0.3[26Y07V3103]

更新日志

  • 1.在KEYWORD类中增加了 cleat 关键字
  • 2.又增加了许多报错（不列了自己去试）
  • 3.增加了+-*/运算和变量相加减
  • 4.增加了clear清屏指令，适配Windows,linux,Macos,Androud

附件：Stars Basic Script V0.3[26Y07V3103].exe
